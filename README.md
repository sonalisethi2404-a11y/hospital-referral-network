# Hospital Referral Network Model

## 📌 Overview
This project helps in optimizing patient referrals between hospitals by suggesting the most suitable hospital based on availability and specialization.

## 🚀 Features
- Suggests best hospital for patient referral  
- Improves patient transfer efficiency  
- Interactive interface for real-time decision support  

## 🛠️ Tech Stack
- Python  
- Streamlit  

## ▶️ How to Run
1. Install required libraries:
   pip install streamlit

2. Run the application:
   streamlit run app.py

## 📊 Use Case
Helps healthcare systems improve patient management and reduce delays in treatment.

## 🔮 Future Improvements
- Integration with hospital databases  
- Real-time bed availability tracking
